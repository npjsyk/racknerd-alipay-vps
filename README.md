## 续费、汇率、限额：几个实际会踩的点

### 自动续费扣不了支付宝

这是最容易忽略的一条。RackNerd 的自动续费会沿用首次下单的扣款方式，而支付宝扫码是一次性授权，系统没法自动发起第二次扣款。**用支付宝付款的，下单后去账单管理把自动续费关掉**，改成手动续费。

忘了续会怎样？到期前一周会收到提醒邮件，收到邮件后进账单管理手动续费，照样能勾支付宝。设个日历提醒比指望自动扣更可靠。

### 汇率和手续费

支付宝按实时汇率折算，和你在支付宝里看到的美金兑人民币牌价基本一致，没有额外的货币转换费。金额大的时候可以拿银联的汇率比一下，哪个划算用哪个。日常几十美元的单子，差不出几块钱。

### 限额看你的支付宝账户

限额跟 RackNerd 无关，取决于你支付宝账户本身的单笔和单日额度。普通账户单笔几千元人民币没问题，年付 $119.99 折合八百多元完全在常规范围内。真要买上千美元一个月的独立服务器，提前确认下自己的额度，不够就提额或者分笔付。
